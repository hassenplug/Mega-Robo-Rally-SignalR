# Game Operation — Required Controls

Commands that need to happen for a game.  These should all be part of a GM screen

## Pre-Event

- [ ] Design boards
- [ ] Print packing list for tiles
- [ ] Edit preconfigured GameData
- [ ] Charge Batteries
  - [ ] Robots
  - [ ] Phones
  - [ ] Game PI Battery
  
## Pre-Game

- [ ] Setup Board & Game
- [ ] Test connection to robots
  - [ ] Start a test game
  - [ ] Check connection to robots; update an IP by hand if needed
  - [ ] Check connection to Phones
  - [ ] End Test Game
- [ ] Pick a pre-created game from a list (pick GameData) & Start

## Starting the Game with Players

- [ ] Disclaimer - This is the first time for Mega Robo Rally
- [ ] Explain the Game
  - [ ] Explain today's timing
  - [ ] Explain the Goal
    - **Players will program the robots to get to the Flags, in order**
  - [ ] Explain Seat & Robot Selection
    - **Players will select their robots and starting positions**
    - **Then they will program robots in order**
    - **The order will rotate so each player will go first at some point**
- [ ] Players pick seats
- [ ] Explain phone orientation
  - **Phones should line up with the board**
  - **Arrows are from your point of view**
  - **If the screens sleep, pull down to refresh**
- [ ] Explain Rules
  - [ ] The goal is to get touch each flag in order
  - [ ] Players will select 5 commands and tap on them
  - [ ] Once all robots are programmed, the first phase will begin
  - [ ] Player 1 will tap Phase ? on their controller or on the robot
  - [ ] Screens will show the order the robots will execute
  - [ ] Players will rotate to the top of the list
  - [ ] Board Elements
    - [ ] Belts
    - [ ] Double Belts
    - [ ] Gears
    - [ ] Pits
  - [ ] Lasers & Spam
  - [ ] Respawn
  - [ ] Shut-Down


## Playing the Game

- **Program phase**
  - [ ] Show current status of players — cards programmed
- **Run phase**
  - [ ] Show current command (skip)
  - [ ] Next phase
- **End of the current game**
  - [ ] 2 hours (or when all flags have been touched)
